🤖 Robot Karol – Programme lesen & interpretieren

Informatik · Klasse 7 · Was macht dieses Programm?
📋 5 Aufgaben 🧱 Ziegel 🟡 Marken 🔵 Weg 🖱️ Interaktives Gitter

📖 So funktioniert diese Seite

Lies das Robot-Karol-Programm und überlege, was Karol macht. Markiere dann im Gitter rechts, wo Karol Ziegel hinlegt, Marken setzt oder welchen Weg er zurücklegt.

1Lies das Programm sorgfältig
2Wähle das passende Werkzeug
3Klicke auf Felder zum Markieren
4Prüfe oder zeige die Lösung
1
Einfache Ziegelreihe
Zählschleife · wiederhole … mal
⭐ Einfach
Karol legt eine Reihe von Ziegeln. Markiere mit dem Ziegel-Werkzeug, auf welchen Feldern Ziegel liegen, nachdem das Programm gelaufen ist.
Hinweis: Hinlegen legt einen Ziegel auf das Feld direkt vor Karol. Schritt bewegt Karol vorwärts.
{ Karol legt 5 Ziegel in einer Reihe }   Programm wiederhole 5 mal Hinlegen Schritt *wiederhole *Programm
→ Karol startet bei Spalte 1, Zeile 2, Blickrichtung: Osten →

Marken im Abstand setzen
Zählschleife · MarkeSetzen
⭐ Einfach
Karol setzt Marken mit einem Abstand von einem Feld. Markiere mit dem Marken-Werkzeug, auf welchen Feldern nach dem Programm Marken liegen.
Hinweis: MarkeSetzen setzt eine Marke auf Karols aktuelles Feld (nicht vor ihm). Die erste Marke auf dem Startfeld ist bereits eingezeichnet (🟡 kleiner Punkt).
{ Karol setzt alle 2 Schritte eine Marke }   Programm wiederhole 4 mal MarkeSetzen Schritt Schritt *wiederhole MarkeSetzen *Programm
→ Karol startet bei Spalte 1, Zeile 2, Blickrichtung: Osten →

4
Quadrat aus Ziegeln – verschachtelte Schleifen
Eigene Anweisung · Zählschleife · 4 Seiten
⭐⭐⭐ Mittel-Hoch
Karol baut ein Quadrat aus Ziegeln. Die Anweisung Seite legt eine Seite des Quadrats und dreht sich an der Ecke. Das Hauptprogramm ruft Seite viermal auf. Markiere alle Felder mit Ziegeln.
{ Karol baut ein Quadrat }   Anweisung Seite wiederhole 3 mal Hinlegen Schritt *wiederhole LinksDrehen *Anweisung   Programm wiederhole 4 mal Seite *wiederhole *Programm

5
Diagonale Treppe – Weg und Ziegel
Kombiniert: Drehen · Schritt · Hinlegen
⭐⭐⭐⭐ Hoch
Karol legt in jeder Schleifen-Runde einen Ziegel, geht einen Schritt, dreht nach Norden ab, macht einen weiteren Schritt und dreht zurück nach Osten. Das Ergebnis ist eine diagonale Treppe. Zeichne sowohl den Weg als auch die Ziegel ein.
{ Karol baut eine Diagonale }   Programm wiederhole 4 mal Hinlegen { Ziegel vor sich } Schritt { auf Ziegel treten } LinksDrehen { nach Norden } Schritt { Schritt nach Norden } RechtsDrehen { wieder Osten } *wiederhole *Programm
→ Karol startet bei Spalte 1, Zeile 5, Blickrichtung: Osten →
